# 대한민국 전력계통 시뮬레이터 (2025 → 2038)

**제11차 전력수급기본계획** 등 정부 공식 계획의 실제 수치를 기반으로, 2025년 현재 전력망에서 출발해 2038년까지 발전·계통·수요가 어떻게 변하는지 보여주는 3D 관찰형 시뮬레이션입니다. 전력산업 종사자·교육용.

> 헤드라인 수치(GW·비중·변전소 수 등)는 계획 공식값이며, 발전소·변전소 등 설비의 지도상 배치는 시각화를 위한 대표 표현입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build && npm run preview   # 프로덕션 미리보기
```

## 배포 (GitHub Pages)

이 앱은 Vite 빌드가 필요하므로 **빌드 결과(dist)** 를 서빙해야 합니다.

- 빌드된 결과가 `gh-pages` 브랜치에 배포되어 있습니다.
- GitHub → Settings → Pages → Source: **Deploy from a branch → `gh-pages` / (root)**.
- 주소: `https://kai01235813-eng.github.io/vpp-game/`
- 소스 수정 후에는 `npm run build` → `dist` 내용을 `gh-pages` 브랜치에 다시 올리면 됩니다.

## 보는 법 (앱 안에서 ❓ 버튼으로도 확인 가능)

- **발전소(공급)** — 원전·석탄·LNG·태양광·풍력·수력. 실제 위치. 마커 hover 시 이름 표시.
- **변전소(계통)** — 🟠 기존(2025, 935개) / 🔴 신설(2038까지 +362, 총 1,297개). 연도가 흐르면 빨간 변전소가 서서히 솟아오름.
- **전력수요 거점** — 반투명 글로우. 크기·색(노랑→빨강)이 수요 규모. hover 시 산업·정책·규모.
- **송전선** — 청록 = HVDC 에너지고속도로 / 보라 = 765kV 교류. 연도에 따라 서해안→U자형으로 점진 형성.
- **고속도로** — 회색. 서·남·동해안 U자 연안축.
- **지역 이름표 클릭** — 권역별 발전소·주요 변전소·전력수요 거점·미래 에너지정책 브리핑.
- **하단 타임라인** — ▶ 자동 재생(2025→2038) / 슬라이더로 연도 이동. 위에 진행상황 라이브 피드(이벤트가 떠올라 페이드아웃).
- **좌측** 전력계통 전망(현재→2038 성장 막대) · **우측** 국가 정책 안내판(연도별 변화·근거). 모바일은 상단 칩으로 열기.
- **날씨·낮밤** 태양광·풍력 발전에 반영(시각 효과).

- 수소특화단지(2024) / 분산에너지 특화지역(2025 후보 7곳) / 신안 8.2GW 해상풍력 / 용인 반도체 15GW

## 기술 구성

- React 18 + Vite + three.js (@react-three/fiber, drei)
- `src/geo.js` 실좌표 투영·외곽선·발전소·송전·고속도로·수요거점·권역 정책
- `src/buildout.js` 연도별 빌드아웃·헤드라인 수치(statsAt)·마일스톤·시기
- `src/substations.js` 변전소 생성(육지 클리핑, 935→1,297, 연도별)
- `src/scene/` 3D 레이어 / `src/ui/` HUD·인트로·가이드
